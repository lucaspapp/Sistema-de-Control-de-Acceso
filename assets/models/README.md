# Modelos locales

Esta carpeta se reserva para los modelos de visión y no se versiona porque sus archivos binarios son pesados.

Para ejecutar el sistema, agregá aquí los archivos usados por `detect.py` y `face.py`:

- `opencv_face_detector.pbtxt` y `opencv_face_detector_uint8.pb`
- `age_deploy.prototxt` y `age_net.caffemodel`
- `gender_deploy.prototxt` y `gender_net.caffemodel`
- `face_detection_yunet_2023mar.onnx` y `face_recognition_sface_2021dec.onnx`
